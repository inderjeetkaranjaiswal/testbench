# TestBench Frontend Service

React + Vite frontend application styled with Tailwind CSS, Lucide React icons, and React Router v6.

## Included Packages
- `react`, `react-dom`
- `react-router-dom`
- `lucide-react`
- `vite`, `@vitejs/plugin-react`
- `tailwindcss`, `@tailwindcss/vite`

## Run Locally
```bash
npm install
npm run dev
```
Development app accessible at `http://localhost:5173`.
